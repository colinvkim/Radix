**Validated performance fixes — 4 September 2026**

Implemented the first two actions from the audit in commits `8aa8ce7` (selection) and `18be262` (cache paths), without new state, caches, or dependencies.

[Selection resolution](/Users/colin/Programming/Radix/Radix/ViewModels/WorkspaceNavigationModel.swift:447) now returns immediately for an empty selection and uses the tree's indexed lookup for one selected ID. Multiselection retains its existing ordering. Extended the existing selection test to check empty, invalid, visible, and off-table selections.

[Volume-capability path normalization](/Users/colin/Programming/Radix/Radix/Services/ScanMetadataLoader.swift:54) uses `URL(filePath:directoryHint: .inferFromPath)` while retaining standardization and trailing-slash normalization. The hint uses the path's trailing slash to determine directory handling, avoiding the old constructor's directory probe. It is available from macOS 13, below Radix's macOS 14 minimum. [Apple documentation](https://developer.apple.com/documentation/foundation/url/directoryhint/inferfrompath). Added a regression test for equivalent dot-component paths, spaces/`#`, trailing slashes, and similarly named volumes. Required dataless, identity, and clone reads remain in place.

Three paired Release rounds compared the preserved original test bundle at revision `b4d1b5dcd554dc2516b14bf2750bc51af7134d06` with the fixed production sources committed in `18be262` on the same Apple M5/APFS machine and generated fixtures.
