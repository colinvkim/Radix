**Unchanged navigation refresh — 4 September 2026**

[WorkspaceNavigationModel](/Users/colin/Programming/Radix/Radix/ViewModels/WorkspaceNavigationModel.swift:365) now skips directory materialization and row-array comparison when the existing rows came from the same immutable tree content ID and containing directory ID. Focusing a file within the displayed directory reuses those rows while still updating the public table context. An empty selection also returns immediately from primary-selection lookup, removing a separate table traversal during snapshot updates.

The source identity belongs to the materialized rows: replacing a tree within the same snapshot reloads metadata, and deferred loading invalidates the identity when it clears rows. It adds one UUID/directory-ID pair, with no additional row array or dictionary. Existing row-revision and publication checks remain in place.
